## Projects

### 1. Assignment 1: What Drives Car Prices?
**Description:** Exploratory data analysis of 201 cars to find the features that most affect car price.

**What I did:**
- Cleaned the data (missing values, duplicates, outliers)
- Described the data with summary statistics and graphs
- Compared average prices by drive-wheels and body-style
- Tested relationships using correlation, ANOVA, and chi-square
- Selected the most important features using SelectKBest and Random Forest

**Key finding:** Engine size, curb weight, and horsepower have the strongest effect on price, and rear-wheel-drive cars cost about twice as much as front-wheel-drive cars.
